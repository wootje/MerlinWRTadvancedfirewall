Country data is downloaded on the router from ebrasha/cidr-ip-ranges-by-country;
reputation data is obtained from the existing Skynet installation and optionally
AbuseIPDB. Those databases are not redistributed in this package. Check the
providers' current terms before use or redistribution.

`countries.json` contains factual country codes, names and aliases used as a
selection catalogue. The original package describes generating these from
pycountry-derived country-name data; the pycountry software is not bundled.

The original uploaded Skynet project ZIP and proprietary firmware assets are not
included in this distribution. The standalone demo uses only synthetic data.
