Decision order

1. Local or special-use IPv4?
Outside this add-on's public-IP checks. The existing router firewall still decides.
2. Country in your selection?
No: block. No reputation lookup is needed for rejected traffic.
3. Listed in a reputation blocklist?
Yes: block. An allowed country does not make a malicious IP safe.
4. Blocked by a port or extra rule?
Otherwise, continue to the existing Merlin/Skynet rules. No ports are opened.

Policy and coverage

Every public IPv4 packet traversing these software chains is checked locally. This is not a fresh online score for every unknown IP. Accelerated traffic and traffic bypassing the router are not automatically covered.

How are ports matched?

Remote peer: destination port outbound, source port inbound. Useful for blocking an external service and its responses.

Destination: the destination port in each packet; inbound this is the public port before port forwarding.

Either: a match on either source or destination blocks the packet. This can also affect an unrelated ephemeral source port with the same number.

GitHub update preferences

Valid intervals: 1–720 hours. Turn off automatic checks for manual-only operation. Turn off Enable GitHub software updates to stop checks, downloads and installations; local rollback remains available. Country and reputation updates are independent.

Only one package is staged. A source archive is limited to 12 MiB, extracted files to 40 MiB. Checks and downloads are deferred during a firewall trial, high load, low RAM or low USB space. The browser polls local status, not GitHub.

Installation and recovery

Installation requires your confirmation and creates an application backup. Private configuration and API keys remain separate. Active kernel rules are not replaced by a software update.

Reload the page after installation. Existing firewall rules continue until a normal policy rebuild or reboot. Hashes detect corruption; they are not independent signatures and do not protect against a compromised repository account. Keep a working SSH session and a router configuration backup.

Preflight check

Activation is refused until preflight passes. This package does not silently change acceleration, WAN administration or IPv6 settings.

SSH recovery

Disable this add-on without clearing the original firewall:

/jffs/scripts/mcg disable

If Python or USB storage is unavailable, flush only this add-on's anchors:

/jffs/scripts/mcg emergency-off

The emergency marker lasts until clear-emergency or reboot. Saved settings remain. Reboot may restore the confirmed policy. Normal disable is persistent. Do not rely on this unvalidated beta as your only protection.

Scope

GT-AX11000 in router mode, Merlin Addons API, Entware Python 3.9+ and IPv6 disabled. Same-switch/bridge traffic, traffic bypassing this router and the encrypted contents of tunnels are not automatically inspected.
